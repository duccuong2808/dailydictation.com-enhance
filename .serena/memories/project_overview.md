# Project Overview

## Purpose
This is a userscript project that enhances the DailyDictation.com website by adding playback speed controls for audio elements. The script provides:
- Speed control buttons (0.25x, 0.5x, 0.6x, 1.0x)
- Keyboard shortcuts (Alt to decrease speed, Shift to increase speed)
- Visual feedback with speed display and highlighted active speed button

## Tech Stack
- Pure JavaScript (ES6+)
- Userscript (Tampermonkey/Greasemonkey compatible)
- DOM manipulation and MutationObserver API
- No external dependencies or build tools

## Target Platform
- Web browser extension (Tampermonkey)
- Works on https://dailydictation.com/*
